# 0.1.0

Initial release.

- Headless `JellyTabBarHeadless` widget with a jelly-animated pill indicator.
- Custom analytical damped-spring physics engine, 1:1 port of `react-native-jelly-tabs`.
- Drag-to-switch, press inflation, track distortion on vertical drag, and radial touch-feedback glow.
- Full accessibility: semantics roles, screen-reader announcements, and keyboard operability.
- Zero runtime dependencies — depends only on the Flutter SDK.
