# flutter_jelly_tabs

A jelly-like animated tab bar with exact behavior, appearance, parameters, and
configuration parity, delivered as a headless, dependency-free Flutter package.

> Built on the VGV AI harness.

## Packages

| Package | Description |
| --- | --- |
| [packages/jelly_tabs](./packages/jelly_tabs) | The headless jelly tab bar Flutter package |
| [example](./example) | Example app demonstrating the tab bar on Android, iOS, and Web |

## Live demo

Try the example app in your browser, no install needed:

<p align="center">
  <a href="https://hieupm2096.github.io/flutter-jelly-tabs/">https://hieupm2096.github.io/flutter-jelly-tabs/</a>
</p>

The web build of the [example](./example) app is deployed to GitHub Pages from
the `main` branch. Run it locally with `flutter run -d chrome` from the
`example/` directory.
